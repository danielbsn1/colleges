# Faculdade — Exercícios e Estudos

Este repositório reúne **exercícios e códigos de estudo** da minha graduação. Não é um projeto de produção nem um produto final: é o meu caderno de prática, onde guardo implementações feitas para aprender e fixar conceitos de **algoritmos, estruturas de dados e lógica de programação**.

> O código aqui reflete o meu processo de aprendizado. Alguns arquivos são simples, outros estão em evolução, e isso é intencional.

## Conteúdo

| Pasta | Linguagem | Assuntos |
|-------|-----------|----------|
| [`python/`](python/) | Python | Algoritmos básicos, vetores, listas, Fibonacci, ordenação, merge sort, saída/impressão de dados |
| [`C/`](C/) | C | Árvore binária, manipulação de strings |
| [`Pascal/`](Pascal/) | Pascal | Manipulação de strings |

## Tópicos estudados

- Estruturas de dados: vetores, listas, árvores binárias
- Algoritmos de ordenação (incluindo merge sort)
- Recursão (sequência de Fibonacci)
- Manipulação de strings
- Comparação de paradigmas e sintaxe entre Python, C e Pascal

## Como executar

**Python**
```bash
python3 python/nome_do_arquivo.py
```

**C**
```bash
gcc C/arvore_binaria.c -o arvore_binaria && ./arvore_binaria
```

**Pascal** (Free Pascal)
```bash
fpc Pascal/string.pas && ./Pascal/string
```
